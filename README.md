# FEYD prototype (recovered deployment build)

This repository contains the recovered, deployable FEYD prototype from the working Vercel deployment. The original editable source repository was empty, so these files are the compiled frontend bundle rather than the original source project.

## Run / deploy

Serve this directory as a static site (for example, with Vercel). `index.html` loads the matching JavaScript and CSS bundles from `assets/`.

## Prototype scope

The prototype uses sample academic data and browser storage for its demo flows. It does not include a production authentication service, remote database, or connected live AI/institute integrations.
